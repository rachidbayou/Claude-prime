Développement avec l'IA

Sélection issue de awesome-vibecoding (version française, vérifiée par ses mainteneurs au 18/09/2026). Les prix et conditions d'accès changent : voir chaque site.

Code et édition

  • Aider (CLI)Pair programming en terminal avec des modèles cloud ou locaux et une intégration Git
  • Claude Code (CLI)Assistant de code agentique avec workflows en terminal et par projet
  • ClineAgent de code pour IDE, terminal et desktop, avec outils fichiers, commandes et navigateur
  • Cursor (IDE)Éditeur et agent de code pour l'implémentation, le débogage et la revue de code
  • Gemini CLI (CLI)Agent de code open source en terminal avec accès par clé API, Vertex ou offre entreprise éligible. L'accès par abonnement grand public est retiré
  • GitHub CopilotAssistance au code et workflows d'agents dans GitHub et les IDE compatibles
  • Goose (CLI)Agent local extensible avec workflows de code, interfaces desktop et CLI, et outils MCP
  • Kiro (IDE)Agent de code AWS avec workflows IDE et CLI, spécifications et tests
  • OpenAI Codex CLI (CLI)Agent de code OpenAI qui s'exécute localement dans le terminal
  • Pi (CLI)Agent de code en terminal, extensible et intégrable comme harnais

Prototypage d'applications et d'interfaces

  • Bolt.new (Web)Création d'applications en langage naturel, par StackBlitz
  • Dyad (Desktop)Créer des applications en local avec des fournisseurs de modèles configurables
  • Lovable (Web)Génération d'applications full-stack avec Supabase
  • Onlook (Web)Modifier visuellement les interfaces d'une application tout en travaillant sur le code
  • Replit (Web)Créer et itérer sur des applications avec Replit Agent
  • v0 (Web)L'IA de Vercel pour générer des UI et du React

Contexte, spécifications et intégrations

  • CaliberCLI qui génère et synchronise les configurations d'agents IA pour Claude Code, Cursor et Codex
  • Context7 (MCP)Récupérer la documentation des bibliothèques comme contexte de code
  • Filesystem MCP (MCP)Donner aux agents un accès contrôlé aux fichiers du projet
  • GitHub MCP (MCP)Connecter les workflows de dépôts, d'issues et de pull requests
  • Neon (MCP)Connecter les workflows de développement aux bases de données Neon
  • Notion MCP (MCP)MCP officiel hébergé pour chercher, lire et mettre à jour du contenu Notion
  • OpenSpecCadre de développement piloté par les spécifications pour assistants de code IA
  • Supabase MCP (MCP)MCP officiel pour les schémas, requêtes et configurations de projet Supabase

Tests, revue et sécurité

  • Agent QA (MCP)Écrire et exécuter des tests web et mobile en langage naturel
  • Playwright MCP (Microsoft) (MCP)Automatisation officielle du navigateur par instantanés structurés des pages
  • PR-AgentRelecteur de pull requests maintenu par la communauté, distinct de Qodo
  • Prbl (Web)Scanner une application en ligne ou un dépôt pour trouver les failles fréquentes du code généré par IA. La GitHub Action commente les PR. Le correcteur Pro applique des corrections vérifiées
  • QodoMoteur de revue de code par IA (anciennement CodiumAI)
  • Semgrep MCP (MCP)Analyse de sécurité MCP via le CLI Semgrep maintenu
  • Sentry (MCP)Inspecter les erreurs d'application et diagnostiquer les échecs

Déploiement et exécution

  • Cloudflare (MCP)Gérer le déploiement d'applications et les ressources cloud
  • E2BSandbox cloud sécurisée pour agents IA de niveau entreprise
  • Publish.my (Web)Publication de sites statiques pilotée par agents, avec activation par email
  • XcodeBuildMCP (MCP)Outils CLI et MCP pour compiler, exécuter et déboguer des projets Apple

Espaces de travail et usage des agents

  • Delta (Zed) (Desktop)Lancer des fils d'agents et relire leurs changements dans un espace de travail multijoueur qui relie conversation et historique du code. Compatible avec les dépôts Git existants
  • Duckweed (Desktop)Exécuter agents de code, shells, diffs Git et sessions dans un espace de travail local multiplateforme
  • llm.logInspecter les coûts, tokens et traces de requêtes des modèles via un proxy local
  • Parallel Code (Desktop)Exécuter des agents de code dans des worktrees Git isolés et relire leurs changements
  • Shep (CLI)Orchestrer des agents de code en parallèle dans des worktrees Git isolés, jusqu'au commit, au push, au suivi CI et aux brouillons de PR
  • Superagent (Desktop)Utiliser Claude Code ou Codex dans un espace de travail macOS avec outils navigateur et iOS
  • usage (Desktop)Voir les quotas des agents de code depuis la barre de menu macOS ou la zone de notification Windows
  • Warp TerminalUtiliser un terminal orienté agents et inspecter les workflows de code
